## Rangkuman Materi Workshop

### 1. AI & Prompt Engineering
* **Definisi Prompt:** Instruksi atau masukan yang diberikan kepada model AI agar menghasilkan keluaran yang relevan dan akurat.
* **Pentingnya Konteks:** LLM tidak memiliki memori jangka panjang yang stabil tanpa adanya konteks yang jelas, sehingga pemberian konteks dapat mengurangi risiko halusinasi pada AI.
* **Struktur Prompt Efektif (Role - Task - Context - Format):** Menentukan peran AI, tugas spesifik, batasan konteks, hingga format hasil yang diinginkan agar respons menjadi optimal.

### 2. Git & GitHub
* **Git:** Sistem pengontrol versi terdistribusi (*Version Control System*) buatan Linus Torvalds yang berfungsi melacak setiap perubahan file dari waktu ke waktu.
* **GitHub:** Platform berbasis web untuk menyimpan *repository* Git secara *cloud* dan mempermudah kolaborasi tim.
* **Alur Kerja Utama Git:** Melibatkan perpindahan file dari *Working Directory* $\rightarrow$ *Staging Area* $\rightarrow$ *Git Repository* (Commit) $\rightarrow$ *Remote Repository* (Push ke GitHub).
